# 🎁 맞춤형 선물 카테고리 AI 추천기

누군가의 생일이나 기념일을 챙겨야 할 때, 받는 사람의 조건과 내 예산에 맞추어 **3초 안에 센스 있는 선물 카테고리 3가지**를 AI로 추천해 주는 웹 도구입니다.

---

## 📌 핵심 기능
1. **예산 범위 설정 슬라이더**: 1만 원부터 30만 원 이상까지 원하는 예산 구간 지정
2. **대상 맞춤 입력**: 연령대, 성별(남/여), 나와의 관계를 각각 따로 선택
3. **Google Gemini AI 즉시 추천**: 입력된 조건을 바탕으로 응답 속도가 빠른 Gemini 모델을 호출하여 최적의 3개 카테고리, 추천 이유, 대표 예시 품목 즉시 출력

> **제외된 기능**: 회원가입, 쇼핑몰 구매 링크, 크롤링, 복잡한 DB 구축은 프로젝트 범위에서 철저히 제외되어 있습니다.

---

## 🚀 로컬 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. API 키 설정 (2가지 방법 중 택1)
* 방법 A: `.env.example` 파일을 복사하여 `.env` 파일을 만든 후 키 입력
  ```env
  GEMINI_API_KEY=AIzaSy...
  ```
* 방법 B: 앱 실행 후 화면 좌측 사이드바에 직접 입력

> **Gemini API 키 발급**: [Google AI Studio](https://aistudio.google.com/)에서 무료로 즉시 발급 가능합니다.

### 3. 웹 도구 실행
```bash
streamlit run app.py
```
실행하면 브라우저에서 `http://localhost:8501`로 자동 접속됩니다.
